## What is ysocial?

ysocial is a microblogging platform for sharing short posts and taking part in conversations. Supporting attachments, emojis, topics, mentions, communities and so much more! No censorship, with as much freedom as possible.

<br />

Repository | Description |

| [**mobile**](https://github.com/ysocialoss/mobile) | The mobile app for phones |

## Get started

- **Try it:** visit the [live site](https://ysocial.cc)
- **Check the code:** start with [`web`](https://github.com/ysocialoss/web) or [`api`](https://github.com/ysocialoss/api)
- **Found a bug or have an idea?** Open an issue in the relevant repository
